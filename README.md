# Альфир, с днём рождения!

Интерактивная страница «Открой свой подарок»: семь конвертов с поздравлениями. Самостоятельный `index.html`, без сборки, внешних шрифтов, аналитики и зависимостей.

## Видео

Видеофайлы хранятся на VPS отдельно от репозитория. Рядом с `index.html` нужна папка `media/`:

| Файл | Поздравление |
| --- | --- |
| `artem.mp4` | От Артёма |
| `ildar.mp4` | От Ильдара |
| `parents.mp4` | От родителей жены |
| `rinat.mp4` | От Рината |
| `marat.mp4` | От Марата |
| `natasha.mp4` | От Наташи |
| `from-wife.mp4` | От жены |

Пути относительные: страницу можно разместить в корне или в подпапке, например `/alfir/` (с завершающим слешем). Видео должно отдаваться с типом `video/mp4` и поддержкой HTTP Range; Nginx умеет это для статических файлов.

## Поведение

- До открытия конверта видео не запрашивается. При открытии загружаются метаданные; воспроизведение начинается по нажатию кнопки в плеере.
- Открытый конверт отмечается при начале воспроизведения, просмотренный — по окончании видео. Состояние сохраняется только в браузере посетителя через `localStorage`; при запрете хранилища страница продолжает работать.
- Видео останавливается при закрытии окна, по Escape, при переключении на другое поздравление. Можно открыть оригинальную ссылку на подготовленный MP4, если плеер не загрузился.
- Доступны управление клавиатурой, возврат фокуса и уменьшение анимации по настройке устройства.

## Размещение

Каталог на VPS: `/var/www/alfir-birthday/`; подготовленные MP4 — в `media/`. HTML необходимо загрузить как `index.html`, не заменяя папку с видео.

Исходные файлы `*-original*` следует хранить за пределами публичной папки сайта. В Git добавляется только код.

Для локального просмотра: `python3 -m http.server 8000` из каталога проекта, затем открыть `http://localhost:8000/`. Видео будут доступны только при наличии локальной папки `media/`.
